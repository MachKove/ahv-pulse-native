# AHV PULSE Native v3 - Electron (Windows) + Capacitor (Android)

## GitHub Actions
Upload all, Actions -> Build AHV PULSE EXE + APK -> Run
Download: AHV-PULSE-Windows-EXE (installer + portable .exe) and AHV-PULSE-Android-APK

## Local
Windows: npm install, npm run dist -> dist/ folder
Android: npm install, npx cap add android, npx cap sync android, cd android, ./gradlew assembleDebug
